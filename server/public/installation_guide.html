Guide d'installation - Photo-booth

Choisissez votre système d'exploitation ci-dessous.

Windows

Supporté : Windows 10 et supérieur

Télécharger

Installation

Téléchargez le fichier.zip

Extrayez-le dans le dossier de votre choix

Lancez Photo-booth.exe

Message de sécurité Windows

Au premier lancement, Windows affichera un message de sécurité car l'application n'est pas signée numériquement.

Ce message est normal. L'application est sûre.

Pour passer ce message :

  1. Cliquez sur "Informations complémentaires"
  2. Puis sur "Exécuter quand même"

Linux

Distribution recommandée : Ubuntu, Debian ...

Télécharger

Installation

Téléchargez le fichier.zip

Extrayez-le

Dans un terminal exécuter la commande

sudo ./install.sh

Le dossier peut ensuite etre supprimé, mais il est conseillé de garder le fichier uninstall.sh

L'application peut etre lancée depuis le menu des applications ou avec la commande photo-booth
