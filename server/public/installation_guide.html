Windows

Télécharger .zip

Supporté : Windows 10 et supérieur

Installation

Téléchargez le fichier .zip

Extrayez-le dans le dossier de votre choix

Lancez Photo-booth.exe

Message de sécurité Windows

Au premier lancement, Windows affichera un message de sécurité, car l'application n'est pas encore signée.

L'application est 100% sûre.

Pour passer ce message :

  1. Cliquez sur "Informations complémentaires"
  2. Puis sur "Exécuter quand même"

Linux

Télécharger

Distributions supportées : Ubuntu, Debian, Fedora...

Installation

Téléchargez et extrayez l'archive.

Dans un terminal, lancez le script d'installation :

sudo chmod +x install.sh && ./install.sh

L'application sera ajoutée à votre menu système.
